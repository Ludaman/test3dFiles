# test3dFiles

This repository contains 3D model assets organized into the following folders:

## F117Obj_small
- `20240618_F117_museum simpleF117Textured.stl` — STL model of the F-117 stealth aircraft
- `F117_small.mtl` — Material library for the F-117 OBJ model
- `F117_small.obj` — OBJ 3D model of the F-117 stealth aircraft
- `F117_small_1.jpg` — Texture image for the F-117 model

## Xwing2
- `Xwing2.jpg` — Texture image for the X-Wing model
- `Xwing2.mtl` — Material library for the X-Wing OBJ model
- `Xwing2.obj` — OBJ 3D model of the X-Wing starfighter

## r2d2
- `R2D2_scan.jpg` — Texture image for the R2-D2 scan model
- `R2D2_scan.mtl` — Material library for the R2-D2 OBJ model
- `R2D2_scan.obj` — OBJ 3D model of R2-D2 (3D scan)
- `R2D2_scan.stl` — STL model of R2-D2 (3D scan)
